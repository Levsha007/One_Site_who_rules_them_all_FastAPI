# My Site – FastAPI Version

Полнофункциональный веб-сайт с коллекцией интерактивных страниц для управления изображениями, закладками, цветами, цитатами, погодой и профилем GitHub. Теперь на **FastAPI**!

---

## 🆕 Что нового в FastAPI версии

* 🚀 **Высокая производительность** — FastAPI один из самых быстрых Python-фреймворков
* 📚 **Автоматическая документация** — Swagger UI доступен по `/docs`
* 🐍 **Python экосистема** — доступ ко всем библиотекам Python
* 🔧 **Асинхронность** — улучшенная обработка множественных запросов
* 📝 **Pydantic валидация** — автоматическая проверка данных
* 🎨 **9+ интерактивных страниц** — полный набор инструментов
* 🌤️ **Новая страница погоды** — умная система прогноза погоды

---

## 🌟 Возможности для пользователей

### 🖼️ Галерея изображений

* Перетаскивание файлов (Drag & Drop)
* Вставка из буфера обмена (Ctrl+V)
* Загрузка по URL
* Множественный выбор файлов
* Создание неограниченного числа папок
* 3D эффекты при наведении на изображения
* Адаптивная Masonry-сетка (1–10 колонок)
* Модальный просмотр с полноэкранным режимом
* Пагинация по 150 изображений на страницу
* Добавление в избранное (локальное хранилище)
* Переименование и удаление изображений

### 📚 Умная система закладок

* Три режима отображения: сетка, список, masonry
* Автоматические категории: Работа, Образование, Игры, Новости, Развлечения, Соцсети, Спорт, Технологии
* Автоматическое получение фавиконов сайтов
* Поиск и сортировка по имени, URL и категории
* Добавление и удаление закладок через модальное окно

### 🎨 Генератор цветов

* HSL слайдеры для точного подбора
* Генерация гармоничных палитр
* Сохранение любимых цветов
* Копирование HEX, RGB, HSL значений
* Случайная генерация
* Визуальный предпросмотр

### 💫 Случайные цитаты

* Цитаты на русском и английском
* Фильтрация по категориям и авторам
* Автоматическое озвучивание текста
* Сохранение в избранное и историю
* Копирование и автообновление по таймеру

### 🌤️ Прогноз погоды (НОВАЯ СТРАНИЦА)

* 150+ городов мира — база координат
* Автоподстановка по городам и странам
* Геолокация — автоматическое определение местоположения
* Текущая погода и прогноз на 5 дней
* Поддержка русского языка
* Адаптивные иконки и оффлайн-кэширование

### ⭐ GitHub Профиль

* Просмотр профиля через GitHub API
* Репозитории, избранное, подписки
* Встроенный просмотр README.md и файлов
* Подсветка синтаксиса, просмотр изображений
* Поиск профилей и переход между ними

### 🎭 Параллакс-страницы

* 🌳 **Параллакс-путь** — многослойная композиция с 3D эффектами
* 🧙‍♂️ **Мир Ведьмака** — параллакс-слайдер с частицами и персонажами
* 🌿 **Grow – Природа** — плавные переходы и анимированные тексты

### 🎯 Персонализация и темы

* Темная/светлая тема (авто и ручное переключение)
* Сохранение выбора между сессиями
* Регулировка размеров плиток и количества колонок
* Полная адаптивность

## 🛠 Технологии

### Frontend

* HTML5, CSS3 (Grid, Flexbox, анимации)
* Vanilla JS (без фреймворков)
* Masonry.js, GSAP, Swiper.js, Canvas API

### Backend (обновлено)

* **FastAPI** — современный высокопроизводительный фреймворк
* Асинхронные запросы с `httpx`
* Валидация через `Pydantic`
* Работа с файлами — `Aiofiles`
* Изображения — `Pillow`
* Конфигурация — `python-dotenv`

### Хранение данных

* JSON — галереи, закладки, цитаты, города
* LocalStorage — пользовательские данные
* .env — API ключи

## 🚀 Установка и запуск

**Требования:** Python 3.8+, pip

```bash
git clone <repository-url>
cd my-gallery-fastapi
pip install -r requirements.txt
uvicorn main:app --reload --port 3000
```

* Сервер: [http://localhost:3000](http://localhost:3000)
* Документация API: [http://localhost:3000/docs](http://localhost:3000/docs)

## 🔌 API Эндпоинты

### Галереи

| Метод | Эндпоинт            | Описание                  |
| ----- | ------------------- | ------------------------- |
| GET   | /api/galleries      | Получить все галереи      |
| POST  | /api/create-gallery | Создать галерею           |
| POST  | /api/upload         | Загрузить изображения     |
| POST  | /api/rename         | Переименовать изображение |
| POST  | /api/delete-image   | Удалить изображение       |

### Закладки

| Метод  | Эндпоинт            | Описание           |
| ------ | ------------------- | ------------------ |
| GET    | /api/bookmarks      | Получить закладки  |
| POST   | /api/bookmarks      | Создать закладку   |
| DELETE | /api/bookmarks/{id} | Удалить закладку   |
| GET    | /api/categories     | Получить категории |

### Цитаты

| Метод | Эндпоинт    | Описание            |
| ----- | ----------- | ------------------- |
| GET   | /api/quotes | Получить все цитаты |

### Погода

| Метод | Эндпоинт              | Описание                |
| ----- | --------------------- | ----------------------- |
| GET   | /api/weather          | Получить текущую погоду |
| GET   | /api/weather/forecast | Прогноз на 5 дней       |
| GET   | /api/weather-api-key  | Проверка API ключа      |
| GET   | /api/cities           | Автоподстановка городов |

## ⚙️ Настройка

### GitHub интеграция

Измените `static/js/github-app.js`:

```js
let currentProfile = 'YourGitHubUsername';
const myUsername = 'YourGitHubUsername';
```

### OpenWeatherMap

Создайте `.env`:

```env
OPENWEATHER_API_KEY=ваш_ключ
```

### Цитаты

```json
{
  "quotes": { "ru": [...], "en": [...] },
  "categories": { "ru": [...], "en": [...] }
}
```

### Города

```json
{
  "cities": [
    { "name": "Москва", "country": "Россия", "lat": 55.7558, "lon": 37.6173 }
  ]
}
```
