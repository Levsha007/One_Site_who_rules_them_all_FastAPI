# My Site – FastAPI Version

Полнофункциональный веб-сайт для управления изображениями, закладками и профилем GitHub с современным дизайном и интерактивными возможностями. Теперь на **FastAPI**!

---

## Что нового в FastAPI версии

* 🚀 **Высокая производительность** — FastAPI один из самых быстрых Python-фреймворков
* 📚 **Автоматическая документация** — Swagger UI доступен по `/docs`
* 🐍 **Python экосистема** — доступ ко всем библиотекам Python
* 🔧 **Асинхронность** — улучшенная обработка множественных запросов
* 📝 **Pydantic валидация** — автоматическая проверка данных

---

## Возможности для пользователей

### Галерея изображений

* Перетаскивание файлов (Drag & Drop)
* Вставка из буфера обмена (Ctrl+V)
* Загрузка по URL
* Множественный выбор файлов
* Создание неограниченного числа папок
* Автоматическое присвоение уникальных имён
* Адаптивная Masonry-сетка (1–10 колонок)
* Модальный просмотр с полноэкранным режимом
* Пагинация по 150 изображений на страницу
* Добавление в избранное (локальное хранилище)
* Переименование и удаление изображений

### Умная система закладок

* Два режима: **сетка** и **список**
* Автоматические категории: Работа, Образование, Игры, Новости, Развлечения, Социальные сети, Спорт, Технологии
* Автоматическое получение фавиконов сайтов
* Поиск и сортировка по имени, URL и категории
* Одно нажатие — переход на сайт
* Добавление и удаление закладок через модальное окно

### GitHub Профиль

* Просмотр профиля через GitHub API
* Репозитории, избранное, подписки
* Встроенный просмотр README.md и файлов кода
* Подсветка синтаксиса
* Навигация по структуре и просмотр изображений
* Поиск профилей и переход между ними

### Параллакс-путь

* 3D эффекты параллакса при скролле
* Многослойная композиция с плавной анимацией
* Динамическое изменение перспективы

### Персонализация и темы

* Темная/светлая тема с автоопределением и ручным переключением
* Сохранение выбора между сессиями
* Регулировка размеров плиток и количества колонок
* Адаптация под любые размеры экранов

## Технологии

### Frontend

* **HTML5** — семантическая разметка
* **CSS3** — Grid, Flexbox, CSS-переменные, анимации
* **Vanilla JavaScript** — без фреймворков
* **Masonry.js** — адаптивная сетка
* **GSAP + ScrollSmoother** — параллакс-анимации

### Backend (обновлено)

* **FastAPI** — современный высокопроизводительный фреймворк
* **Асинхронные запросы** — быстрая обработка множества операций
* **Pydantic** — автоматическая валидация данных
* **Pillow (PIL)** — обработка и оптимизация изображений
* **Aiofiles** — асинхронная работа с файлами

### Хранение данных

* **JSON-файлы** — галереи, закладки, категории
* **LocalStorage** — пользовательские предпочтения
* **Файловая система** — загруженные изображения

## Установка и запуск

### Предварительные требования

* Python 3.8+
* pip

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd my-gallery-fastapi

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера разработки
uvicorn main:app --reload --port 3000
```

Сервер доступен по адресу: [http://localhost:3000](http://localhost:3000)

Документация API: [http://localhost:3000/docs](http://localhost:3000/docs)

## API Эндпоинты

### Галереи

| Метод | Эндпоинт              | Описание                  |
| ----- | --------------------- | ------------------------- |
| GET   | `/api/galleries`      | Получить все галереи      |
| POST  | `/api/create-gallery` | Создать новую галерею     |
| POST  | `/api/upload`         | Загрузить изображения     |
| POST  | `/api/rename`         | Переименовать изображение |
| POST  | `/api/delete-image`   | Удалить изображение       |

### Закладки

| Метод  | Эндпоинт              | Описание              |
| ------ | --------------------- | --------------------- |
| GET    | `/api/bookmarks`      | Получить все закладки |
| POST   | `/api/bookmarks`      | Создать закладку      |
| DELETE | `/api/bookmarks/{id}` | Удалить закладку      |
| GET    | `/api/categories`     | Получить категории    |

## Настройка

### GitHub интеграция

В файле `static/js/github-app.js` измените:

```javascript
let currentProfile = 'YourGitHubUsername';
const myUsername = 'YourGitHubUsername';
```

### Темы

Темы настраиваются через CSS-переменные в `:root` и `[data-theme="light"]`.

### Лимиты загрузки

* Максимальный размер файла: **500 MB**
* Максимальное количество файлов: **3000**
* Поддерживаемые форматы: **JPEG, PNG, GIF, WebP, SVG, BMP, TIFF, AVIF, HEIF**
