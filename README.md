# My Site – FastAPI Version

Полнофункциональный веб-сайт с коллекцией интерактивных страниц для управления изображениями, закладками, цветами, цитатами и профилем GitHub. Теперь на **FastAPI**!

---

## 🆕 Что нового в FastAPI версии

* 🚀 **Высокая производительность** — FastAPI один из самых быстрых Python-фреймворков
* 📚 **Автоматическая документация** — Swagger UI доступен по `/docs`
* 🐍 **Python экосистема** — доступ ко всем библиотекам Python
* 🔧 **Асинхронность** — улучшенная обработка множественных запросов
* 📝 **Pydantic валидация** — автоматическая проверка данных
* 🎨 **8+ интерактивных страниц** — полный набор инструментов

## 🌟 Возможности для пользователей

### 🖼️ Галерея изображений

* Перетаскивание файлов (Drag & Drop)

* Загрузка по URL

## 🛠 Технологии

### Frontend

* **HTML5** — семантическая разметка
* **CSS3** — Grid, Flexbox, CSS-переменные, анимации
* **Vanilla JavaScript** — без фреймворков
* **Masonry.js** — адаптивная сетка
* **GSAP + ScrollSmoother** — параллакс-анимации
* **Swiper.js** — слайдеры
* **Canvas API** — матричный дождь и частицы

### Backend (обновлено)

* **FastAPI** — современный высокопроизводительный фреймворк
* **Асинхронные запросы** — быстрая обработка множества операций
* **Pydantic** — автоматическая проверка данных
* **Pillow (PIL)** — обработка и оптимизация изображений
* **Aiofiles** — асинхронная работа с файлами

### Хранение данных

* **JSON-файлы** — галереи, закладки, категории, цитаты
* **LocalStorage** — пользовательские предпочтения, избранное
* **Файловая система** — загруженные изображения

## 🚀 Установка и запуск

### Предварительные требования

* Python 3.8+
* pip

### Установка

```bash
git clone <repository-url>
cd my-gallery-fastapi
pip install -r requirements.txt
uvicorn main:app --reload --port 3000
```

Сервер: [http://localhost:3000](http://localhost:3000)
Документация API: [http://localhost:3000/docs](http://localhost:3000/docs)

## 🔌 API Эндпоинты

### Галереи

| Метод | Эндпоинт            | Описание                  |
| ----- | ------------------- | ------------------------- |
| GET   | /api/galleries      | Получить все галереи      |
| POST  | /api/create-gallery | Создать новую галерею     |
| POST  | /api/upload         | Загрузить изображения     |
| POST  | /api/rename         | Переименовать изображение |
| POST  | /api/delete-image   | Удалить изображение       |

### Закладки

| Метод  | Эндпоинт            | Описание              |
| ------ | ------------------- | --------------------- |
| GET    | /api/bookmarks      | Получить все закладки |
| POST   | /api/bookmarks      | Создать закладку      |
| DELETE | /api/bookmarks/{id} | Удалить закладку      |
| GET    | /api/categories     | Получить категории    |

### Цитаты

| Метод | Эндпоинт    | Описание            |
| ----- | ----------- | ------------------- |
| GET   | /api/quotes | Получить все цитаты |

## ⚙️ Настройка

### GitHub интеграция

Измените `static/js/github-app.js`:

```javascript
let currentProfile = 'YourGitHubUsername';
const myUsername = 'YourGitHubUsername';
```

### База цитат

Файл `data/quotes.json`:

```json
{
  "quotes": { "ru": [...], "en": [...] },
  "categories": { "ru": [...], "en": [...] }
}
```

### Темы

Настройка через CSS-переменные в `:root` и `[data-theme="light"]`.

### Лимиты загрузки

* Максимальный размер файла: **500 MB**
* Максимум файлов: **3000**
* Поддерживаемые форматы: JPEG, PNG, GIF, WebP, SVG, BMP, TIFF

## 📊 Форматы данных

### Галерея

```json
{
  "name": "Название",
  "folderPath": "uploads/название",
  "images": [
    {
      "path": "/static/uploads/name.jpg",
      "name": "Опциональное имя",
      "width": 1920,
      "height": 1080,
      "isExternal": false
    }
  ]
}
```

### Закладка

```json
{
  "id": 123456789,
  "title": "Название",
  "url": "https://example.com",
  "category": "Категория",
  "createdAt": "2024-01-01T00:00:00.000Z"
}
```

### Цитата

```json
{
  "text": "Текст цитаты",
  "author": "Автор",
  "category": "motivation",
  "tags": ["вдохновение", "успех"],
  "language": "ru"
}
```
